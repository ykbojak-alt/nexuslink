NEXUSLINK · USER GUIDE01 · ПРИНЦИП РАБОТЫ
Локальный шлюз (gateway)

Что NexusLink делает для вас

Claude отправляет привычный запрос Anthropic, NexusLink переводит его в формат провайдера и возвращает ответ, в том числе потоковый.

Форматы

Преобразует Anthropic messages в OpenAI chat completions и обратно. SSE-поток также переводится в события Anthropic.

Слоты моделей

claude-sonnet-5 и другие Claude ID указывают на реальные upstream-модели.

Ротация

При 401/402/403/429 ключ временно убирается из пула; следующую попытку получает другой ключ или провайдер.

Важно

Клиент подключается к 127.0.0.1:5679. Несколько провайдеров на одном слоте образуют fallback по порядку в конфиге. Некорректный запрос 400 не маскируется ротацией.

Контекст

system становится первым сообщением role:system.

Инструменты

tool_use и tool_result переводятся в OpenAI tool calls и ответы.

Рассуждение и поток

reasoning_content становится thinking-блоком; SSE переводится обратно в Anthropic events.

NEXUS LUX03 / 12
NEXUSLINK · ПЕРВЫЙ ЗАПУСК03 · ПРОВАЙДЕРЫ И ПАНЕЛЬ
Шаг 2 · запуск

Создайте конфигурацию и откройте панель

1

В терминале выполните nexuslink init. Если файла ещё нет, команда создаст его и сгенерирует incoming_token.

%USERPROFILE%\.nexuslink\config.json (Windows)
~/.nexuslink/config.json (macOS / Linux)
2

Для desktop-приложения с системным треем запустите nexuslink app. X скрывает окно в трей; правый клик по значку → «Выход» завершает процесс.

3

Для панели в браузере запустите nexuslink ui. Команда поднимает gateway и открывает страницу управления.

Адрес панели
http://127.0.0.1:5679/#t=<incoming_token>

Токен находится во фрагменте после #t=. Фрагмент не отправляется серверу вместе с запросом страницы.

Важно

Без настроенного токена прокси отвергает запросы. Не оставляйте его пустым.

4

Добавьте провайдера, ключи и модели. Кнопка Save & apply live сохраняет конфиг и горячо обновляет прокси без рестарта.

Совет

Панель редактирует тот же config.json. В секции ROTATION BLACKLIST видны временно припаркованные ключи.

NEXUS LUX04 / 12
NEXUSLINK · CONFIG.JSON04 · КЛЮЧИ И СЛОТЫ
Шаг 3 · конфигурация

Пример с пулом ключей и двумя слотами

Замените демонстрационные значения своими. Не используйте ключи из скриншотов как настоящие.

{
  "incoming_token": "nl-REPLACE_WITH_LOCAL_TOKEN",
  "port": 5679,
  "providers": [{
    "name": "OpenRouter",
    "base_url": "https://openrouter.ai/api",
    "api_keys": ["sk-or-DEMO-KEY-1", "sk-or-DEMO-KEY-2"],
    "chat_path": "",
    "supports_reasoning_effort": false,
    "use_max_completion_tokens": true,
    "models": [
      {"name":"meta-llama/llama-3.1-70b-instruct","slot":"claude-sonnet-5"},
      {"name":"qwen/qwen-2.5-72b-instruct","slot":"claude-haiku-4-5"}
    ]
  }]
}

Поля, которые влияют на запрос

ПолеЗначение
base_urlКорень OpenAI-совместимого API. Для стандартного маршрута не добавляйте завершающий /v1. Пример: https://openrouter.ai/api.
api_keysПул ключей провайдера. При 401/402/403/429 неудачный ключ временно пропускается, затем пробуется следующий.
chat_pathПереопределение пути chat-completions. Пустое значение использует /v1/chat/completions.
use_max_completion_tokenstrue отправляет max_completion_tokens; false отправляет max_tokens. По умолчанию true.
supports_reasoning_effortОтправляет reasoning_effort. Включайте, только если провайдер поддерживает это поле.
models[].name / slotname - реальный ID у провайдера; slot - Claude ID, например claude-sonnet-5.
Важно

Если два провайдера используют один слот, порядок в массиве providers задаёт fallback-цепочку.

NEXUS LUX05 / 12
CLAUDE DESKTOP · DEVELOPER MODE05 · АВТОМАТИЧЕСКИЙ ПУТЬ
Шаг 4a · рекомендуемый путь

Подключите Claude Desktop командой apply

1

Убедитесь, что incoming_token непустой и добавлен хотя бы один провайдер.

2

Выполните nexuslink apply. Команда напечатает точные пути файлов и результат.

3

Проверьте файл в Claude-3p/configLibrary. Запись атомарная; несвязанные поля существующего файла сохраняются.

Основные значения в configLibrary

"inferenceProvider": "gateway",
"inferenceGatewayBaseUrl": "http://127.0.0.1:5679",
"inferenceGatewayApiKey": "<incoming_token>",
"inferenceGatewayAuthScheme": "bearer",
"inferenceStreamIdleTimeoutSec": 1800
"inferenceModels": [
 {"name":"claude-sonnet-5",
  "supports1m":false,
  "labelOverride":"meta-llama/llama-3.1-70b-instruct"}
]
ID файла

Если Claude уже выбрал файл, apply обновляет его ID. Иначе использует ID NexusLink b0b0b0b0-c2c2-4d3d-8e8e-f5f5f5f5f5f5 и регистрирует его в _meta.json.

Пути Windows

Обычный: %LOCALAPPDATA%\Claude-3p\configLibrary
Fallback: %APPDATA%\Claude-3p\configLibrary
MS Store: %LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude-3p\configLibrary

macOS / Linux

~/Library/Application Support/Claude-3p/configLibrary
~/.config/Claude-3p/configLibrary

В satellite-файлы claude_desktop_config.json записываются deploymentMode:"3p" и mcpServers.nexuslink (команда - путь к nexuslink.exe, аргументы ["mcp"]). MCP также добавляется в ~/.claude.json; skill устанавливается в ~/.claude/skills/nexuslink-video/SKILL.md.

Дополнительные поля gateway: coworkEgressAllowedHosts:["*"], disableDeploymentModeChooser:true, chatTabEnabled:true, modelDiscoveryEnabled:false.

Шаг 4b · без apply

Введите адрес gateway вручную

Используйте этот путь, если не хотите применять настройки командой nexuslink apply.

1

Откройте Claude Desktop → Settings → Developer / Third-party inference / Gateway. Подписи могут немного различаться между версиями.

2

В поле Base URL введите http://127.0.0.1:5679, без /v1.

3

В поле API key вставьте значение incoming_token из конфига.

4

Добавьте слоты, настроенные в NexusLink: claude-sonnet-5 и claude-haiku-4-5.

Внимание

Ручной gateway не регистрирует MCP. Для автоматической установки generate_video и video_status выполните nexuslink apply.

Сверьте значения

Gateway URL
http://127.0.0.1:5679

Слоты
claude-sonnet-5
claude-haiku-4-5

CLAUDE DESKTOP · ПРОВЕРКА07 · РЕСТАРТ И МОДЕЛЬ
Шаги 4c-4e · применить и проверить

Полностью перезапустите Claude Desktop

1

Откройте системный трей, нажмите значок Claude правой кнопкой и выберите Quit / Выход.

2

Запустите Claude Desktop снова. Закрытие крестиком не завершает процесс полностью.

3

Выберите модель. Селектор показывает реальное upstream-имя через labelOverride.

Подсказка

В configLibrary поле name остаётся Claude-слотом, а labelOverride показывает имя модели провайдера.

4

Отправьте короткое тестовое сообщение и убедитесь, что появился ответ.

5

В списке инструментов MCP найдите generate_video и video_status.

Макет чата · пример успешного ответа
Claude · тест gateway
Пользователь: Ответь одним словом: готово.
meta-llama/llama-3.1-70b-instruct · gateway
Готово.

Все окна Claude Desktop на этой странице - схематичные макеты, не реальные скриншоты.

NEXUS LUX08 / 12
CLAUDE CODE · MCP VIDEO08 · ТЕРМИНАЛ И ИНСТРУМЕНТЫ
Шаг 5 · Claude Code

Используйте те же слоты в Claude Code

После nexuslink apply MCP зарегистрирован в user scope. Gateway получает адрес и токен из переменных окружения.

1

Для ручного запуска в PowerShell задайте переменные и выполните Claude Code:

$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:5679"
$env:ANTHROPIC_AUTH_TOKEN = "<incoming_token>"
claude
2

Командой /model выберите настроенный слот.

3

Применение также записывает эти env в ~/.claude/settings.json и регистрирует MCP в %USERPROFILE%\.claude.json (Windows) или ~/.claude.json.

видео через MCP

Два инструмента, одна зависимость

generate_video
Текстовый prompt, необязательные seconds и aspect_ratio. Модель сервера: agnes-video-2.5-flash.

video_status
Проверяет задачу по video_id, возвращает прогресс или URL готового видео.

Внимание

Добавьте Agnes provider с API-ключом. Без него сервер вернёт честную ошибку no Agnes provider configured. Наличие инструмента в списке само по себе не активирует видеосервис.

NEXUSLINK · УСТРАНЕНИЕ НЕПОЛАДОК09 · БЫСТРЫЕ РЕШЕНИЯ
Шаг 6 · если не работает

Найдите причину по симптому

СимптомЧто проверитьДействие
Порт занятДругой процесс слушает 127.0.0.1:5679. Ошибка: cannot bind 127.0.0.1:5679.Остановите предыдущий gateway или измените port и Base URL.
401 / ключи не подходятПроверьте баланс, права ключей, base_url и авторизацию у провайдера.Ключи с 401/402/403/429 попадают в blacklist. Смотрите маскированный статус в панели или /api/status.
400 · unmapped slotClaude отправляет слот, которого нет в models[].slot.Добавьте slot для реальной модели, сохраните конфиг и повторите запрос.
Панель просит токенНет фрагмента #t=... или токен не совпадает.Откройте панель через nexuslink ui или введите incoming_token в token gate.
Поток замолкUpstream не присылает данные более 15 секунд.NexusLink добавляет SSE heartbeat : ping; Claude timeout при apply - 1800 секунд.
macOS блокирует запускDMG не подписан сертификатом разработчика.Правый клик по приложению → Открыть при первом запуске.

Ключи и blacklist

Ключ паркуется на 15 минут. В /api/status видны маскированный хвост и остаток времени. Blacklist хранится в памяти и очищается при рестарте.

Слоты и модели

Сверьте точное написание слота в models[].slot и списке Claude Desktop.

Совет

Изменения через панель применяются без рестарта NexusLink. После правки gateway-настроек Claude Desktop перезапустите полностью через трей.

NEXUS LUX10 / 12
NEXUSLINK · БЕЗОПАСНОСТЬ10 · ГРАНИЦЫ ДОВЕРИЯ
Шаг 7 · защита данных

Токен и ключи остаются секретами

NexusLink слушает только loopback, но локальный адрес сам по себе не является авторизацией.

на входе

Claude → NexusLink

Клиент отправляет incoming_token как Bearer-токен или x-api-key. Неверный или отсутствующий токен отклоняется.

на выходе

NexusLink → провайдер

В upstream Authorization уходит ключ провайдера. Входной токен туда не пересылается.

1

Оставьте bind на 127.0.0.1. Не публикуйте порт gateway в локальную сеть или интернет.

2

Храните токен и ключи в пользовательском ~/.nexuslink/config.json, не в общем каталоге проекта.

3

На Unix задайте права chmod 600 ~/.nexuslink/config.json.

4

Не добавляйте рабочий конфиг в Git, архивы, тикеты или скриншоты.

Внимание

Ключи провайдеров хранятся в config.json открытым текстом. Если вы показали рабочий ключ на скриншоте или переслали его, отзовите его у провайдера.

Совет

Фрагмент #t=<token> не попадает в HTTP-запрос страницы, но сам токен всё равно не пересылайте другим людям.
